# Plant Engine v0.1.2

iPadを主対象とした、植物相談用のPWAプロトタイプです。チャット型AIではなく、現地カルテ・植物データベース・条件照合・組み合わせ検証を行う専門家用ワークベンチとして設計しています。

## 現在できること

- 現地写真の取り込み
- 地域、寸法、日照、土壌水分、高さ上限の入力
- 葉色・葉形・季節性・役割による植物候補の抽出
- 適合度と除外理由の表示
- 採用候補と株数の管理
- 成長後の概算占有量の計算
- 冬の構成、葉形、三層構成、繁殖性の検証
- 相談案件の端末内保存
- 写真をGitHubへ送らず、iPad内の写真用データベースに保存
- 相談メモのコピー
- PWAとしてホーム画面への追加とオフライン起動

## 起動

このフォルダで静的Webサーバーを起動してください。

```bash
python3 -m http.server 8080
```

Macでは `http://localhost:8080` を開きます。

## GitHub Pages

このフォルダをGitHubリポジトリの `main` ブランチへ置くと、同梱のワークフローがGitHub Pagesへ自動公開します。リポジトリの Settings → Pages → Source で **GitHub Actions** を選択してください。

公開されるのはHTML、CSS、JavaScript、植物データだけです。相談者の写真や相談内容はGitHubへ送信されず、利用中のiPad内に保存されます。
