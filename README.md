# Garden OS v0.7

Garden OS is a calm garden memory and observation system.

## Current flow
Garden Setup → Create first bed → Look → Save photo → Timeline → Repeat Photo → Then↔Now → Plant Instance → Garden Map

## GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.
5. Open the generated Pages URL in Safari or Firefox.
6. On iPhone Safari, Share → **Add to Home Screen**.

Data is stored locally in the browser with `localStorage`.
